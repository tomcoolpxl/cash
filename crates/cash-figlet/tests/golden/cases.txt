# Cases compared with figlet 2.2.5 (Arch's, in WSL): name|options|message.
# The message is words split at blanks, as figlet's command line gives them, or after a
# `<` text for standard input, `\n` a newline. `-C utf8` makes figlet read UTF-8, as cash
# always does; cash reads it as a control file that changes nothing.
# Regenerate the .out files with generate.sh after changing this list.
