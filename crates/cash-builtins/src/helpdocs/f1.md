## PATHS   cash prints paths as C:/Users/me; every program understands them
  cd C:/Users/me/src             forward slashes, no quotes needed
  cd "C:\Users\me\src"           backslashes must be quoted in scripts;
  cd 'C:\Program Files\Git'        pasted from Explorer, unquoted works here
  cd /c/Users/me  ·  cd ~/src    cash itself understands /c/ and ~
  tool.exe "$(winpath -w "$d")"  an old tool that wants backslashes
  echo "$PATH"                   the one colon-separated /c/... variable

## KEYS
  Alt-E        pick a file or folder in a tree, filter by typing
  Alt-← Alt-→  back and forward through the folders you were in
  Tab          complete, with a menu on the second press
  →            accept the dimmed suggestion from your history
  Ctrl-R       search the history as you type
  Alt-.        last word of the previous line   Ctrl-X Ctrl-E  edit in $EDITOR

## MORE
  Bash scripts run as they are; `ls`, `awk`, `sed`, `find` and {tools} are built in.
