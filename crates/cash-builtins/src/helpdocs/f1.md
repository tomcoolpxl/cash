## PATHS
  cash prints paths as C:/Users/me, and every program understands them.
  cd C:/Users/me/src             forward slashes need no quotes
  cd C:\Users\me\src             pasted from Explorer: works at the prompt
  notepad C:\Users\me\a.txt      Windows programs get the path as typed
  cd "C:\Users\me\src"           in a script, backslashes need quotes
  cd /c/Users/me                 the /c/ form works too
  cd ~/src                       ~ is your home directory
  cd \\server\share              a network share, as Explorer writes it
  winpath -w ~/src               prints C:\Users\me\src, for tools that need \
  echo "$PATH"                   PATH alone is /c/... and colon-separated

## KEYS
  Alt-E                          pick a file or directory from a tree
  Alt-← Alt-→                    back and forward through directories you were in
  Tab                            complete; press again for a menu
  →                              accept the dimmed suggestion from history
  Ctrl-R                         pick from the history: Enter edits, Tab runs
  Alt-.                          last word of the previous line
  Ctrl-X Ctrl-E                  edit the line in $EDITOR

## MORE
  Bash scripts run as they are; `ls`, `awk`, `sed`, `find` and {tools} are built in.
  z WORD                         go to a directory you often go to: z cash
  help                           every built-in command, by kind
  help NAME                      help for one command
  help topics                    paths, keys, config and the other topics
  man NAME                       the whole manual page, in your browser
  cash doctor                    check the install
  start FILE                     open a file in its Windows app
  sudo CMD                       run a command elevated
